# Prácticos de Lenguajes IV (UCASAL, 2026)

Trabajos prácticos de la materia Lenguajes IV de Ingeniería en Informática (Comisión 1). Van de las APIs del
navegador con JavaScript puro a aplicaciones con React y rutas.

**Sitio con todos los prácticos:** https://agusfar45.github.io/lenguajes-iv-tp8/

| Práctico | Tema | Tecnologías |
|---|---|---|
| [TP 1](tp1/) | Geolocalización e imagen | Geolocation API, JavaScript |
| [TP 2](tp2/) | Geolocalización e historial | Geolocation API, almacenamiento local |
| [TP 3](tp3/) | Explorador de imágenes | File API |
| [TP 4](tp4/) | Laboratorio Blob | Blob y `slice()` |
| [TP 5](tp5/) | Blob en React | React, Vite |
| [TP 6](tp6/) | Componentes | React |
| [TP 7](tp7/) | Rutas | React Router |
| [TP 9](tp9/) | Posada del Valle: reservas | React · código fuente en [codigo-tp9/](codigo-tp9/) |

Los TP 5 a 9 están compilados con Vite para publicarlos en GitHub Pages. El código fuente del TP 9 está en
`codigo-tp9/`, y también en [tp9-lenguajes-iv](https://github.com/agusfar45/tp9-lenguajes-iv).

El proyecto integrador de la materia es mi
[portfolio fullstack](https://github.com/agusfar45/proyecto-integrador-lenguajes-iv).
